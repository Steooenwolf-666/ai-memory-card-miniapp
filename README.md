# AI Memory Card Miniapp / 记忆卡片 Pro

一个基于微信小程序云开发的记忆卡片复习工具，面向学生和知识工作者的日常学习场景。项目当前版本聚焦 MVP：卡片创建、待复习列表、复习反馈、间隔复习时间更新和每日订阅提醒。后续可扩展接入 LLM，将长文本笔记自动拆解为问答卡片、概念卡和错题卡。

## 项目背景

很多学习工具解决的是“记录”问题，但没有很好地解决“什么时候复习、复习哪些内容、复习后如何更新下一次复习时间”的问题。本项目尝试用微信小程序承载一个轻量级学习闭环：

1. 用户录入知识点或学习笔记；
2. 系统保存为记忆卡片；
3. 首页展示今日待复习卡片；
4. 用户根据掌握情况反馈“全部记住 / 部分记住 / 需要重学”；
5. 系统根据反馈更新下一次复习时间；
6. 云函数定时触发订阅消息提醒。

## 核心功能

- 卡片管理：创建、查看、编辑、删除记忆卡片。
- 复习状态：支持“待学习”“全部记住”“部分记住”“需要重学”等状态。
- 间隔复习：根据复习反馈设置下一次复习时间，例如 1 天、3 天、7 天。
- 今日任务：首页展示当前需要复习的卡片列表。
- 订阅提醒：通过云函数定时扫描待复习卡片，并向订阅用户发送提醒。
- 云开发支持：使用微信云数据库保存 cards 和 users 数据。

## 技术栈

## 数据设计

### cards 集合

| 字段 | 说明 |
| --- | --- |
| title | 卡片标题 |
| content | 卡片内容 |
| status | 当前复习状态 |
| createTime | 创建时间 |
| updateTime | 更新时间 |
| nextReviewDate | 下次复习时间 |
| _openid | 微信云开发自动生成的用户标识 |

### users 集合

| 字段 | 说明 |
| --- | --- |
| subscriptionStatus | 是否开启订阅提醒 |
| createTime | 创建时间 |
| updateTime | 更新时间 |
| _openid | 微信云开发自动生成的用户标识 |

## 本地运行

1. 使用微信开发者工具导入本项目。
2. 在 `app.js` 中将 `your-env-id` 替换为自己的云开发环境 ID。
3. 开通云开发，并创建 `cards` 和 `users` 两个集合。
4. 建议将集合权限配置为“仅创建者可读写”。
5. 部署 `cloudfunctions/dailyReminder` 云函数。
6. 在订阅消息能力开通后，将代码中的 `your-template-id` 替换为实际模板 ID。

## 当前状态

这是一个 MVP 版本，已经完成核心学习闭环，但仍有可优化空间：

- 接入 LLM，将长文本自动生成问答卡片；
- 引入更完整的 SM-2 或 FSRS 间隔重复算法；
- 增加卡片分类、标签、搜索和统计页面；
- 增加学习热力图、复习完成率和遗忘率分析；
- 增加错误处理和端到端测试。

- 论文阅读笔记复习
